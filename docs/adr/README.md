# Architecture Decision Records — Odin-Skills

Decision records for **this project**: how the skills the Odin harness owns are packaged, licensed
and published. Harness-design decisions live in the harness's own `.claude/docs/adr/`.

**Ids here are this project's own sequence**, numbered from 0001 and independent of the harness
sequence. Cite one from outside this project as `odin-skills:ADR-NNNN` (harness ADR-0050,
`projects/README.md` rule 7). Format follows the harness template — MADR-lite, with the date on the
`Status` line.

The *decision* in an Accepted ADR is immutable: supersede it with a new record rather than rewriting
it. Factual corrections — a stale path, a drifted count, a broken link — are maintenance and are made
in place.
